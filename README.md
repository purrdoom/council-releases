# Council

A full-screen workspace for making short-form vertical videos: script with Claude or Grok, generate shots, edit on a timeline, and export, all on one screen.

This page holds the Windows installers and release notes. Download the latest **Council-Setup** file from [Releases](https://github.com/purrdoom/council-releases/releases). Once installed, Council updates itself.

> Windows may show "Windows protected your PC" because the app is not code-signed yet. Click **More info**, then **Run anyway**.
